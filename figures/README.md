# Figuras

Imágenes del paper con nombres en `snake_case`, sin espacios, tildes ni símbolos.
Son copias de `actual/Imagenes/`; los originales no se tocan.
`main.tex` las encuentra con `\graphicspath{{figures/}}`, así que en `\includegraphics` va solo el nombre del archivo.

Las figuras de resultados que genere el laboratorio (`ips-dos-ics-lab/figures/`) se copian aquí con el mismo criterio de nombres.
